## Notas de uso

- Las imágenes se almacenan en el repositorio para evitar hotlinking y dependencias externas en tiempo de ejecución.
- `next/image` genera variantes responsivas y sirve WebP/AVIF según el navegador; el archivo base se conserva a 1600 px de ancho.
- Si se reemplaza una imagen, actualiza esta tabla con el nuevo autor y la URL de origen.
- Las fotografías son ilustrativas: no representan necesariamente las instalaciones reales del club.
